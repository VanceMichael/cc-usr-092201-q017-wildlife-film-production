# 野生动物故事摄制

保存野生动物真实故事的来源、许可、素材和成片审签资料。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`。当前记录类型包括事实访谈、剧本场次、人物授权、取景许可、拍摄素材、发布版本，状态示例为资料核实 → 剧本审签 → 待拍摄 → 摄制中 → 剪辑中 → 已发布。这些样例使用虚构标识，不含真实个人资料、账号或连接凭据。

已整理的业务事实：

- 影片取材于受伤雪豹的真实救助经历
- 故事聚焦一线生态管护人员
- 摄制地点位于重要生态保护区域

## 摄制后台

`production_backend/` 在领域资料之上实现覆盖资料核实到成片发行的后台服务，样例数据见 `fixtures/production.json`（受伤雪豹“凌小芒”救助故事，人物、机构、坐标均为虚构）：

- **资料核实与剧本审签**：访谈与救助档案核实后才能支撑场次过审；关键情节必须可追溯到已核实来源。
- **授权、许可与生态约束**：人物授权按范围（肖像/姓名/访谈引用/经历改编）限定素材用法；取景许可与生态影响评估限定区域、期限与行为。
- **改编边界标注**：场次按史实还原/细节改编/情节虚构分级，改编处必须填写与史实的边界说明。
- **每日拍摄通告**：开机前按日期核对许可、生态评估、临时关闭与待办复核，给出各区域能否进入及允许/禁止行为，不含精确坐标。
- **再审签触发**：剧本修改、当事人撤回授权、保护区临时关闭、疑似素材泄露、海外翻译变化都会开具对应审签工单，办结前阻断流程推进与发布。
- **敏感坐标分级**：精确坐标存于保险库，仅制片人、外联制片、生态顾问可查看，访问与被拒均留痕。
- **剪辑溯源**：`trace_scene` 输出场次的来源、授权、素材与异常清单。
- **发布审签**：`certify_release` 逐项核查场次审签、关键情节依据、改编标注、授权有效、素材隔离、位置脱敏、许可覆盖与未完成审签；`release_dossier` 向发布负责人提供结论加全程留痕。

## 本地校验

项目自带的测试会读取样例并检查领域标识、版本、记录类型、流程状态和事实说明，并覆盖摄制后台的核实、授权、通告、溯源与发布核查流程。后续服务应继续兼容这份公开资料约定。

```bash
python -m unittest discover -s tests
```
