# 野生动物故事摄制

保存野生动物真实故事的来源、许可、素材和成片审签资料。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`。当前记录类型包括事实访谈、剧本场次、人物授权、取景许可、拍摄素材、发布版本，状态示例为资料核实 → 剧本审签 → 待拍摄 → 摄制中 → 剪辑中 → 已发布。这些样例使用虚构标识，不含真实个人资料、账号或连接凭据。

已整理的业务事实：

- 影片取材于受伤雪豹的真实救助经历
- 故事聚焦一线生态管护人员
- 摄制地点位于重要生态保护区域

## 本地校验

项目自带的测试会读取样例并检查领域标识、版本、记录类型、流程状态和事实说明。后续服务应继续兼容这份公开资料约定。
