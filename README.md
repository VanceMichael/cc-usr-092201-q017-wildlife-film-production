# 野生动物故事摄制

保存野生动物真实故事的来源、许可、素材和成片审签资料。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`。记录类型覆盖摄制后台全流程：事实访谈、救助档案、剧本场次、人物授权、取景许可、生态影响评估、拍摄许可、拍摄通告、拍摄素材、审签记录、发布版本。流程状态为资料核实 → 剧本审签 → 待拍摄 → 摄制中 → 剪辑中 → 已发布；任何阶段因变更事件退回的记录进入"变更复核"。这些样例使用虚构标识，不含真实个人资料、账号或连接凭据。

领域资料还约定了：

- 来源追溯：剧本场次登记事实访谈或救助档案来源并标注改编边界，剪辑人员可沿场次追查关键情节依据
- 使用限定：人物授权、取景许可、生态影响评估、拍摄许可共同限定素材可以怎样使用
- 每日确认：现场人员开机前按拍摄通告确认当天允许进入的区域和行为
- 变更再审签：剧本修改、当事人撤回授权、保护区临时关闭、疑似素材泄露、海外翻译变化分别进入对应复核
- 坐标分级：敏感坐标按县级、保护区分区、精确坐标分级，仅向必要岗位开放，发布物料不得超出县级精度
- 发布核查：发布负责人凭完整审签记录确认成片未暴露位置、未歪曲救助过程、未越权使用素材

已整理的业务事实：

- 影片取材于受伤雪豹的真实救助经历
- 故事聚焦一线生态管护人员
- 摄制地点位于重要生态保护区域
- 保护机构不公开栖息地精确坐标
- 拍摄不得为画面再次干扰野生动物
- 艺术改编处须标出与史实的边界

## 本地校验

项目自带的测试会读取样例并检查领域标识、版本、记录类型、流程状态、事实说明，以及角色坐标知悉、变更触发与发布核查等后台约定。`domain_context/loader.py` 做最小兼容检查，`contracts/domain.schema.json` 是当前完整结构约定。后续服务应继续兼容这份公开资料约定。
